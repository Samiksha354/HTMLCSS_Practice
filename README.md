# 🚀 30 Days of HTML & CSS Practice

A hands-on **30-day HTML & CSS practice challenge** where I build one small project every day to strengthen my frontend development fundamentals.

The goal is not to build complex projects immediately, but to practice consistently, improve my understanding of HTML and CSS, and gradually move from simple UI components to complete responsive interfaces.

---

## 🎯 Challenge Goals

- Strengthen HTML fundamentals
- Improve CSS skills through hands-on practice
- Understand Flexbox and responsive layouts
- Practice forms and user interface components
- Improve problem-solving while building UIs from scratch
- Build consistency through daily practice
- Gradually create more complex frontend projects
